# Corrección de especialidades en Administración

La pantalla **Registrar avance** de administración ahora presenta exactamente estas especialidades de bachillerato:

- Administrativo Contable
- Mantenimiento Automotriz
- General
- Salud
- Desarrollo de Software
- Servicios Turísticos

Los códigos internos siguen siendo `ADM`, `AUTO`, `GRAL`, `SAL`, `SOFT` y `TURISMO`. `NOCTURNO` se integra a `General` y `SOST` se excluye del selector de especialidad.
